The Brodfest website, as a self-contained WordPress plugin.

== Description ==

Runs on the BlueWorx Enhance theme, which looks after the admin, sign-in and
security. This plugin draws the public site: it creates its own pages and
renders them itself, so the design is exact whatever else is installed.

== Installation ==

1. Activate the BlueWorx Enhance theme.
2. Install this plugin's zip through Plugins → Add New → Upload Plugin and
   activate it. Its pages are created and Home becomes the front page.

3. Under Brodfest in the admin, choose Save the Date or Invite, add the home
   page videos, and set where RSVP replies are emailed.
